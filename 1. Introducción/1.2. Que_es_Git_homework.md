Escribe el comando exacto de Git para responder a cada uno de los siguientes escenarios reales de desarrollo:

### Desafío 1: El Mensaje Directo

Tienes tus cambios listos y quieres hacer un commit con el mensaje `"Fix: corregido el error en el formulario"`. Escribe el comando en una sola línea evitando abrir el editor de texto:

```bash
# Tu respuesta aquí:

```

---

### Desafío 2: Creación vs Navegación

Estás en la rama `main`. Quieres crear una rama paralela llamada `feature/login`, **pero NO quieres moverte a ella todavía** (quieres permanecer trabajando en `main`). ¿Qué comando debes usar?

```bash
# Tu respuesta aquí:

git checkout feature/login

```

---

### Desafío 3: El Salto Cuántico (Modo Clásico vs Modo Moderno)

Te piden crear una nueva rama llamada `fix/bug-header` y **ubicarte en ella inmediatamente**.

1. Escribe el comando usando la sintaxis **clásica** (`checkout`):

```bash
# Respuesta clásica:

git checkout -b fix/bug-header

```

2. Escribe el comando usando la sintaxis **moderna** (`switch`):

```bash
# Respuesta moderna:

git switch -c fix/bug-header

```
